# LayaKit

The Laya CoreML runtime from [FluidInference/FluidUse](https://github.com/FluidInference/FluidUse) (`Sources/FluidUse/Laya`, commit `cfba4d3`), copied unchanged under its Apache-2.0 licence (`LICENSE`). Vendored instead of depending on FluidUse, because FluidUse's library also pulls in FluidAudio.

It runs `FluidInference/laya-coreml`, a CoreML build of `convaiinnovations/laya-multilingual` (Apache-2.0).
